# Lyra asset source
Artwork: Luis Zuno / Ansimuz, Warped Caves. CC0/public domain.
Source: https://opengameart.org/content/warped-caves-pixel-art-pack
Downloaded 2026-09-20: https://opengameart.org/sites/default/files/warped-files_1.zip
Original PNG files and license retained without modification. No music or demo code is used.
Runtime palette mapping in src/lyra-candidate.ts adapts magenta armor to cyan/blue and hair to indigo. Alpha and geometry remain unchanged.
Fixed crop (0,20,80,44), pivot x=40; all frames share their original 80x80 canvas and foot baseline.
Four idle and ten run frames. Dialogue uses idle; this asset does not include speaking poses.
